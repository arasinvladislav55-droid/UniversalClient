# Сборка программы и выпуск обновлений

## Один раз: настройка
1. Установите **JDK 21**, **Maven** и **WiX Toolset 3.x** (нужен jpackage для .exe), всё должно быть в PATH.
2. Создайте репозиторий на GitHub (публичный — чтобы лаунчер мог читать version.json без авторизации).
3. Ссылки на ваш репозиторий `arasinvladislav55-droid/Universal-Client` уже прописаны в `Updater.java` и `build.ps1`.
   Если ветка называется не `main`, поправьте её в `UPDATE_URL`.

## Сборка установщика
```
powershell -ExecutionPolicy Bypass -File build.ps1
```
Результат в папке `dist`: `UniversalClient-<версия>.exe` (установщик) и `version.json`.
Первый раз раздайте людям этот .exe. Установка — в профиль пользователя, права администратора не нужны.

## Выпуск обновления
1. Поменяйте `LAUNCHER_VERSION` в `core/Config.java` (например, `2.5.0` → `2.6.0`). Версия в `pom.xml` — по желанию.
2. Запустите `build.ps1`.
3. На GitHub: Releases → New release → тег `v2.6.0` → прикрепите `dist/UniversalClient-2.6.0.exe`.
4. Впишите, что нового, в `dist/version.json` (поле `notes`) и закоммитьте его в корень репозитория (ветка main).
5. Всё. У пользователей при следующем запуске (или в течение 15 минут) вместо «ИГРАТЬ» появится «ОБНОВИТЬ».

## Как это работает у пользователя
Лаунчер читает `version.json`. Если `version` новее встроенной `LAUNCHER_VERSION` — кнопка меняется на «ОБНОВИТЬ»,
запуск игры блокируется. По нажатию скачивается установщик (проверяется SHA-256), запускается, лаунчер закрывается.
Установщик заменяет старую версию (благодаря неизменному `--win-upgrade-uuid`); настройки и профили в
`%APPDATA%\.universalclient` сохраняются. После установки запустите лаунчер из меню «Пуск».

## Что где в коде
- `core/Updater.java` — проверка `version.json` на GitHub, скачивание установщика (с проверкой SHA-256) и его запуск.
- `ui/LauncherApp.java` — проверка при старте и каждые 15 минут; если версия на GitHub новее, кнопка «ИГРАТЬ» превращается в «ОБНОВИТЬ», запуск игры и вход на серверы блокируются до обновления.

## Важно
- `$UpgradeUuid` в `build.ps1` никогда не меняйте — иначе обновление поставится рядом со старой версией.
- Собирать .exe нужно на Windows (под каждую ОС — на ней самой).
- Если хотите не принуждать к обновлению, а лишь предлагать — уберите проверку `pendingUpdate` в `LauncherApp.play`/кнопке.
