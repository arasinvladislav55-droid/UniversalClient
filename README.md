# Universal Client Launcher 2.5

Лаунчер Minecraft (выбор версий 1.19 — 1.21.11) для визуального клиента. JavaFX, Java 21, Maven.

## Запуск из IntelliJ IDEA
1. File → Open → выбрать папку проекта (или `pom.xml` → Open as Project).
2. File → Project Structure → SDK = **JDK 21**.
3. Maven → Reload All Maven Projects.
4. Запускать класс **`org.example.Main`** (НЕ `LauncherApp`) или Maven: `javafx:run`.

## Сборка одного .jar
```
mvn package
java -jar target/UniversalClient-Launcher.jar     (нужна Java 21)
```

## Что внутри
- Экран входа с профилями (offline), «запомнить меня», смена профиля
- Единый тёмный стиль, анимации, фон с частицами
- Выбор версии Minecraft (релизы 1.19 — 1.21.11, по умолчанию 1.21.11) с поиском и фильтрами; всё докачивается автоматически
- Логи: `%APPDATA%\.universalclient\logs\launcher.log` (кнопка в настройках)
- Фирменный ресурспак «Rounded UI» (см. ниже) — ставится и включается автоматически
  (отключается в Настройки → «Фирменное оформление Minecraft»)
- Данные: `%APPDATA%\.universalclient`

## Оформление Minecraft «Rounded UI» (2.5)
Игра полностью перекрашена под лаунчер. Пак собирается в 5 вариантов — по одному на цветовую тему лаунчера
(фиолетовый, океан, роза, изумруд, закат) и подставляется автоматически по выбранной теме при каждом запуске игры.

Что изменено в Minecraft:
- закруглённые кнопки (обычная / при наведении / отключённая) с градиентом и бликом, цвет наведения = цвет темы;
- слайдеры (+ ползунок), поля ввода, чекбоксы с галочкой, вкладки, полоса прокрутки;
- подсказки предметов (скруглённая рамка цвета темы), уведомления (достижения, рецепты, системные);
- хотбар со скруглёнными ячейками, рамка выбранного слота со свечением, полоса опыта;
- фоны меню и списков (бесшовная тёмная сетка), разделители шапки/подвала;
- процедурная космическая панорама главного меню в цветах темы, логотип UNIVERSAL, надпись VISUAL CLIENT, сплэши.

Пак работает на Minecraft 1.21 — 1.21.11. На 1.19 — 1.20.x он отключается автоматически (там другой формат GUI и логотипа).
Готовые паки лежат в `src/main/resources/pack/` и в папке `ResourcePacks/` — их можно положить в `.minecraft/resourcepacks` вручную.

## Пересборка графики
`python tools/generate_assets.py` (Pillow + numpy) — пересоздаёт все 5 паков.
`python tools/generate_assets.py --preview` — дополнительно рисует `tools/preview_<тема>.png` (макет меню).
Цвета тем, сплэши и размеры скруглений меняются в начале скрипта. Иконку лаунчера рисует `tools/generate_assets_v1_old.py`.

## Discord Rich Presence
Статус в профиле Discord («Играет в …», время, версия, ник). Инструкция — `discord/README.txt`;
ассет для Art Assets — `discord/logo.png`. Application ID встроен в программу — пользователям ничего вводить не нужно (нужен только запущенный Discord).

## Интерфейс 2.3
- Анимация открытия (заставка с пиксельным логотипом) и кастомное окно с тенью, акцентной линией и «хлебными крошками» в заголовке
- Новая главная: герой-карточка с кубиками, статистика (версия, память, время в игре, запуски), «Что нового», быстрый доступ
- Меню: Главная, Версии, Скриншоты, Профиль, Оформление, Настройки, О программе
- Оформление: 5 цветовых тем (применяются мгновенно), отключение частиц и свечений
- Профиль: статистика, UUID, список профилей. Скриншоты: галерея из папки игры

## Экран входа 2.4
Двухпанельная карточка в цветах выбранной темы: парящие кубики и смена слайдов слева; быстрый вход по профилям (плитки с аватарами),
живой аватар при вводе ника и приветственная анимация справа.

## Меню 2.5
К прежним пунктам добавлены:
- **Серверы** — избранные серверы с онлайном, пингом, версией и MOTD; «Играть» запускает игру и сразу заходит на сервер
  (`--quickPlayMultiplayer` для 1.20+, `--server/--port` для 1.19).
- **Хранилище** — сколько места занимают версии, библиотеки, ресурсы, папка игры и логи; свободное место; сведения о Java и системе.
